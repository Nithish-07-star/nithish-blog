# Learning Journal 3- Experience of Group Project 2

Nov 2nd 2026

## GROUP PROJECT 2 – RAJDHANI

### Introduction

Overall Group Project 2 was an interesting experience. We had to complete a range of tasks and create a number of features for the Rajdhani train booking system. I enjoyed working on this project as I was able to learn new things and understand how programming works in real life situations. However, I did face some challenges with my group members.

### Experience

I enjoyed working on this project. I found it interesting to complete all of the tasks and understand how the different features worked. Some of the tasks were easy to understand however others took more effort.

I was able to complete a number of tasks which overall meant I completed over 16 tasks. I was happy to understand the tasks and implement them. I learnt how to work with Python files, JSON data and different functions.

The project was interesting as I had to understand the existing code, read through the instructions and think about how to implement each feature.

### Challenges

An issue that I faced during this project was working with my group members. I didn’t feel like they were working well together.

As I wanted to complete more tasks I struggled with the lack of teamwork. I was only able to complete up to Task 12 however I had completed over 16 tasks.

This was frustrating as I had spent a lot of time on this project and if I’d done it alone I could’ve completed more tasks.

### Debugging

Another challenge I faced was working with Git. As we were using Git to collaborate I think there were issues with pushing and pulling.

Something wasn’t working and I couldn’t push my completed tasks. I’m not entirely sure why this happened but I think it was down to the way we were using Git.

This has taught me that even if we complete our code we need to ensure our changes are saved properly. I now understand I need to learn more about Git.

### Teamwork

One of the most frustrating parts of this project was working with my teammates. I was expecting us to work well together, divide up the tasks and support each other with any issues we had. However, I didn’t feel we were working well together.

Sometimes I felt that I would’ve found this project easier if I’d done it alone. If I had done this alone I’d have been able to complete around 18+ tasks.

However I understand that group projects are to teach us teamwork. I have learnt that communication and teamwork is very important.

### Was it worth creating?

Overall I think this project was worth completing. Although I did have issues with teamwork I enjoyed the technical side of this project.

I was able to learn new concepts and understand how different aspects of the program work together. I was also able to put my knowledge into practice.

Although I wasn’t able to submit all of my completed tasks I feel that the time I spent was beneficial.

### What I learnt

I have learnt more about Python, JSON files and understanding existing code.

I have learnt that it’s not just important to complete the tasks but that you need to ensure your work is shared.

I have learnt the importance of Git, communication and teamwork. I have also realised that I need to be more careful when working with shared files.

### What I would do better next time

If I was given the opportunity to do this again I would try to improve the way I work with my team.

I would communicate better with my teammates and ensure they know what their role is. I would also try to learn Git properly to prevent any issues.

I would ensure my completed tasks are saved properly.

### Conclusion

Overall Group Project 2 was an interesting but frustrating experience. I enjoyed working on the project and learning new things however I struggled with the lack of teamwork and Git issues.

Although I was disappointed that my completed tasks weren’t included I have learnt lots of useful things.

I hope to put this into practice in the future to improve my technical skills and teamwork.
