# My Learning Journey in Craft of Computing

Throughout this course, I learned many new things about computing and programming. Initially, I was not very familiar with programming, terminal commands and working with different tools.

During the course, I learned Linux terminal commands, Bash scripting, file management, Markdown and Pandoc. I also gained experience with Python programming, functions, JSON files and debugging.

The group projects gave me an opportunity to apply these concepts practically. In the first project, I worked with Bash scripts and Pandoc to convert Markdown files into HTML pages. In the second project, I worked with Python to develop features for the Rajdhani train booking system. I also explored electronic components, ESP32 and sensors through practical activities.

One important thing I learned was that programming is not just about writing code. It also involves identifying errors, testing solutions, understanding how different tools work and solving problems step by step.

Overall, this course gave me practical experience and helped me become more confident in exploring computing. It also increased my interest in learning more about technology and programming.
